# Relay 右键效率交互与现代主题升级设计

**状态：** 已实现（2026-09-17）。Context Menu、终端/Server/SFTP/标签页右键动作、7 套主题预设和偏好设置预览已落地；自定义主题编辑器、团队共享和跨平台同步仍按非目标延期。

**目标：** 在不破坏终端输入、剪贴板安全和 Local-first 数据边界的前提下，为 Relay 建立统一的右键效率交互，并把当前简单的三套主题升级为完整的语义化主题系统。

## 1. 用户范围

本次设计覆盖四类交互对象：

1. SSH 终端内容区：选中复制、粘贴、全选、清屏、搜索等高频操作。
2. Server 卡片：连接、SFTP、复制连接信息、收藏、编辑、测试和安全管理。
3. Server 标签：卡片内标签和左侧标签筛选项使用一致的右键菜单。
4. SFTP 文件列表和终端标签：作为第二阶段的统一效率扩展，复用同一菜单基础设施。

右键菜单不是把所有按钮重复一遍，而是根据当前对象提供上下文动作；危险操作与普通操作分组显示。

## 2. 右键菜单边界

Relay 工作区内容区禁止浏览器默认右键菜单，并由 Relay 提供自定义菜单。以下区域保留浏览器原生菜单：

- `input`、`textarea`、`select` 和 `contenteditable` 编辑区；
- 链接和文件选择控件；
- 显式标记了 `data-native-context-menu="true"` 的控件。

这样既能满足终端、Server 和 SFTP 的应用内操作，也不会阻断输入框的系统粘贴、链接新标签打开和辅助技术工作流。

菜单必须支持：

- 鼠标打开和触控长按预留入口；
- 键盘上下移动、Enter 执行、Escape 关闭；
- 点击外部、滚动或窗口失焦关闭；
- 靠近视口边缘时自动反向定位；
- 复制、粘贴失败时显示可理解的反馈；
- 所有危险动作仍需已有的二次确认流程。

## 3. 终端交互

终端右键菜单首批动作：

- 复制选中内容；没有选区时禁用；
- 粘贴；无剪贴板能力时禁用；多行或较长文本继续二次确认；
- 全选；
- 清除选区；
- 搜索终端输出；
- 清屏；
- 打开当前 Server 的 SFTP；
- 新建 Console（存在 Server 选择器时显示）。

键盘规则：

- 有选区时 `Ctrl/Cmd+C` 复制选区；
- 无选区时 `Ctrl+C` 继续传递给远端作为中断信号；
- `Ctrl/Cmd+V` 走 Relay 的剪贴板读取、确认和粘贴流程；
- 不把右键直接绑定为无确认粘贴，避免误执行剪贴板中的命令。

## 4. Server 和标签菜单

### Server 卡片

普通动作：

- 进入 Console；
- 打开 SFTP；
- 复制 `user@host:port`；
- 复制 SSH 命令；
- 测试连接；
- 收藏或取消收藏；
- 编辑 Server。

安全动作单独分组：

- 清除 Host Key 信任；
- 删除 Server。

右键菜单不能提供密码、私钥、passphrase 或其他 secret 的复制入口。

### Server 标签

卡片内标签和左侧标签筛选项提供：

- 按此标签筛选；
- 复制标签文本；
- 清除当前标签筛选（当前已选中时）。

当前数据模型没有独立标签实体，因此本次不提供“重命名标签”；避免只改单个 Server 或产生无法同步的半完成操作。

## 5. 第二阶段文件和标签页菜单

SFTP 文件条目右键菜单：

- 下载文件；
- 复制远程路径；
- 进入目录；
- 重命名；
- 删除（确认）。

终端标签右键菜单：

- 激活标签；
- 编辑 Server；
- 关闭标签；
- 关闭其他标签；
- 打开该标签对应的 SFTP。

这些动作不改变现有状态机和权限边界，只把已有操作放到上下文位置。

## 6. 主题系统

主题从“名称 → 少量颜色”升级为“主题预设 → UI 语义 Token + xterm ANSI 调色板”。每个预设至少定义：

- 页面、面板、卡片、输入框和浮层背景；
- 边框、分隔线、悬停、选中和焦点颜色；
- 主文本、次文本、弱文本；
- 主色、成功、警告、错误和连接状态色；
- 终端背景、前景、光标、选区和 ANSI 16 色；
- `color-scheme` 和浏览器 `theme-color`。

首批预设：

- Relay Midnight；
- Relay Light；
- Nord；
- Dracula；
- Solarized Dark；
- OLED Black；
- High Contrast。

首批只做经过验证的预设，不引入复杂的颜色编辑器。后续再增加实时预览、自定义色板、字体/光标配置和按 Server/分组的环境色标识。

主题仍保存在现有 `relay.ui.preferences.v1` 本地设置中；未来账号登录后的同步沿用现有同步规划，不把主题选择和凭据同步混为一体。必须继续使用 `data-relay-theme`，不能恢复使用容易被浏览器扩展覆盖的通用 `data-theme`。

## 7. 非目标

- 不改变 SSH、SFTP、Host Key 或凭据安全策略；
- 不上传剪贴板内容、终端完整输出或 secret；
- 不把浏览器原生菜单替换到 Relay 之外的页面；
- 不在本次加入团队共享、自定义主题编辑器或新的账号同步协议；
- 不因 UI 主题变更重写 shared core 或服务端数据模型。

## 8. 验收标准

- 终端选中文本可以通过右键和 `Ctrl/Cmd+C` 复制；无选区的 `Ctrl+C` 仍能中断远端命令。
- 终端右键粘贴经过现有确认和错误反馈流程。
- Server 卡片、卡片标签、左侧标签筛选项均能打开对应右键菜单。
- 删除和清除 Host Key 信任仍然二次确认，菜单不会暴露 secret。
- 输入框和链接的原生右键能力不被破坏。
- 刷新后用户已选择的主题保持不变；未保存设置仍使用 Relay 默认主题。
- 每个主题同时影响 Relay UI 和 xterm 终端，且不受第三方扩展的 `data-theme` 属性覆盖。
- 菜单和主题在 320px 窄屏、键盘导航和高对比模式下可用。
