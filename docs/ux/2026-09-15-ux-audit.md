# Relay Web SSH 用户体验走查记录

日期：2026-09-15

## 走查方式

本轮安排了四组“代理模拟用户”并行走查。它们不是外部真实用户访谈，而是基于产品需求和当前代码执行的可复现用户路径审查；所有结论都要求有代码、DOM 或端到端测试证据。

| 模拟用户 | 重点路径 |
| --- | --- |
| 首次使用者 | 创建 Vault → 添加 Server → 首次指纹确认 → 输入命令 → 返回列表 |
| 多 Server 运维用户 | 多 Console、同一 Server 多页签、分屏、切换 Pane、关闭与恢复 |
| 移动/触控用户 | 320px 宽度、长主机名、分屏、触控拖拽、下拉刷新与短视口 |
| 安全/辅助用户 | 错误密码、指纹变更、锁定/解锁、焦点、Escape、ARIA 与状态播报 |

## 已改进

- 修复收藏请求成功后错误执行回滚，确保收藏状态与服务端一致。
- 首次连接成功后自动聚焦 Console；在 Console 焦点下保留 `Ctrl/Cmd+K` 打开 Server picker、`Ctrl/Cmd+W` 关闭当前 Console 的快捷键。
- 连接成功后刷新 Server 元数据，返回列表可立即看到“指纹已验证”和最近连接时间。
- 永久 SSH 错误（认证失败、指纹不匹配、协议错误等）不再自动重连；可恢复的网络断线仍保留指数退避，并显示下一次重试时间。
- 锁定后清理终端状态并在重新解锁后回到 Server 列表，不再落到空终端页。
- 分屏 Pane 点击时同步活动 Console；分隔线支持 Tab 聚焦、方向键/Home/End 调整，并扩大触控语义支持。
- 修复 320px 下长主机名撑破 Server 卡片的问题，连接操作保持在视口内。
- 添加 Server 抽屉和偏好设置补齐 dialog 语义、首焦点、Tab 循环、Escape 关闭、点击遮罩关闭和关闭后焦点恢复。
- 将“测试连接成功/需要确认指纹”与红色错误提示分离，使用可读的状态反馈。
- Console 状态增加 `aria-live`，重连时显示约等待秒数。

## 验证证据

- 状态层回归：收藏成功提交后保留服务端确认值；永久错误关闭后不创建新 Socket。
- DOM 回归：分屏 Pane 活动同步、分隔线键盘调整、状态反馈、抽屉/偏好设置焦点与 Escape。
- Chromium 端到端：Vault 初始化、Server 添加、首次指纹确认、直接输入命令、滚动策略、返回列表元数据、多 Console、刷新恢复、分屏、锁定/解锁，以及 320px 长主机名不溢出。

## 后续项

以下项目在本轮确认存在，但没有冒险扩大改动范围：

- 已保存 host key 发生变更时，提供“查看旧/新指纹并清除旧信任后重新确认”的完整安全流程。
- 极短高度或软键盘可视区域下，自动避免上下分屏把 Console 压缩到不可用高度。
- 返回 Server 列表时保持活动 SSH 会话挂载，避免暂时离开列表导致前台进程退出；若不保持，则需要在界面明确提示会话已暂停/关闭。

这些项目应分别补充后端安全接口、移动端真实设备验证和会话生命周期设计后再实现。
